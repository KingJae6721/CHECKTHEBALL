# 골대 옆 세로 슛 게이지

- 공 소유 중 골대 옆에 옅게 표시하고 좌클릭 슛 충전 중 선명하게 활성화한다.
- 주황색이 아래에서 위로 차오르며, 녹색 구간 중심은 실제 림 중심의 화면 Y 좌표에 맞춘다.
- 실제 렌더 카메라를 사용하므로 시선·점프·카메라 시각 오프셋을 반영한다. 게임 좌표에는 쓰지 않는다.
- 골대 옆 X 기준점은 월드에 고정한다. 화면 밖/카메라 뒤/너무 잘린 위치에서는 숨긴다.
  가장자리에서는 높이를 줄여 정렬을 유지하며 녹색 구간만 임의로 이동시키지 않는다.
- 공 미소유·메뉴·패스 충전 중에는 숨긴다. 패스 POWER는 기존 하단 가로 게이지를 유지한다.
- 충전 최대 1.2초와 이상적인 충전 .7초는 유지한다. 녹색 구간과 실제 PERFECT 판정은
  릴리스 순간 플레이어의 수평 골대 거리에 따라 함께 좁아진다.
  같은 시간 오차의 궤적 영향도 거리에 따라 커진다. 무작위 명중 확률은 추가하지 않는다.
- 거리별 초기 튜닝: `packages/game-core/src/court.ts`의 `SHOT_TIMING`.

  | 거리 | 이상적인 시간 대비 허용 폭 | 녹색 구간 |
  | --- | --- | --- |
  | 1.5m 이하 | ±0.09초 | 0.61–0.79초 |
  | 6.75m | ±0.0375초 | 0.6625–0.7375초 |
  | 8m 이상 | ±0.025초 | 0.675–0.725초 |

  중간 거리는 선형 보간하며 경계는 PERFECT에 포함하지 않는다.
  수치는 시작 설정이며 측정된 성공률이 아니다. 이상적인 타이밍의 궤적은 유지한다.
  화면과 판정은 `shotTiming.ts`를 공유하고 오프라인/온라인 모두 같은 슛 함수를 사용한다.
- 튜닝: `apps/web/game/shotMeterLayout.ts`의 `SHOT_METER`. 스타일: `globals.css`의 `hoop-meter-*`.
- `createHoopShotMeter.ts`가 DOM을 한 번 생성하고 렌더 프레임에서 위치/채움 스타일만 갱신한다.
  매 프레임 React 상태/텍스처를 생성하지 않으며 Scene 해제 시 제거한다.

기존 세로 배치에서 실행한 검증: 관련 레이아웃 테스트 2개, 웹 타입 검사, `node scripts/probe-hoop-meter.mjs`.
브라우저 probe는 별도 Scene의 실제 카메라 투영과 소유/충전 상태를 이용해 녹색 중심-림 Y 차이
1px 이내, 조준 변경, 미소유/패스/카메라 뒤 숨김, DOM 정리를 검사했다. 스크린샷은 없다.
실제 온라인 두 창의 슛 입력/지연까지 검증한 것은 아니다. 전체 테스트/빌드는 실행하지 않았다.

사용자 확인: 공 소유 → 골대를 보며 좌클릭 유지 → 녹색과 림 높이 비교 → 이동/점프하며 확인 →
슛 릴리스 후 숨김 → 패스 충전 시 기존 가로 POWER 확인.

거리별 변경 검증: 관련 자동 테스트 16개와 웹/서버 타입 검사 통과.
골밑/중거리/3점 녹색 폭과 같은 타이밍 실수의 결과를 수동 비교한다.
충전 중 이동하면 현재 거리로 녹색 폭이 바뀌며 실제 릴리스 위치에서 판정한다.
온라인 확인에는 갱신된 게임 서버가 필요하다. 이번 거리별 변경의 브라우저 플레이 감각과 빌드는 미검증이다.
