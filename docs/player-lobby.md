# PLAYER LOBBY — 정적 캐릭터 로비

중앙 카드 대신 왼쪽 메뉴 38% / 오른쪽 코트·캐릭터를 배치했다. 짙은 청록색·아이보리,
연두색 빠른 플레이·주황색 선택 표시를 사용한다. 주요 버튼은 20~24px, 본문은 16px 기준이다.
헤더에서 게스트 닉네임을 편집하며 기존 검증/저장 키, 설정·안내·크레딧·BGM 수명은 유지한다.

## 기능 연결

| 조작 | 실제 동작 |
| --- | --- |
| 1대1 / 2대2 | 기존 duel / teamDuel 선택. 주황색과 aria-pressed로 표시 |
| 2대2 빠른 플레이 | 기존 서버 예약/생성/참가/취소 경로 |
| 1대1 빠른 플레이 | 1대1 자동 매칭은 현재 없다. 기존 공개 방 목록을 1대1 필터로 열어 직접 선택. 버튼 밑에 안내 |
| 방 찾기 | 선택 모드 목록. 필터에서 모든 방/연습도 선택 가능 |
| 방 만들기 | 선택 모드를 기본값으로 기존 생성 화면. 연습 방 생성도 유지 |
| 코드로 참가 | 기존 정확한 Room ID 참가와 오류 복구 |
| 혼자 연습 | 기존 시나리오 선택 후 실제 연습 시작 |

첫 화면 복귀 시 연습 방 모드 선택을 대응하는 1대1/2대2 선택으로 정리한다.
빠른 플레이 취소/실패는 로비로 돌아오며 늦은 연결은 기존 세대 검사로 leave한다.
목록 조회만으로 예약/입장이 발생하지 않는다. 서버·공·경기·예측 규칙은 변경하지 않았다.

## 변경 파일과 에셋

- `app/PlayerLobby.tsx`: HTML 메뉴 및 별도 `LobbyBackdrop` 배경/캐릭터 영역.
- `app/playerLobby.css`: 로비 전용 반응형 스타일. 실제 플레이 HUD는 기존 스타일 유지.
- `app/Game.tsx`: 기존 액션/프로필 연결. 플레이 전 Engine/Scene/Room 생성 없음.
- `app/OnlineMenu.tsx`: 현재 선택 모드의 방 목록 필터. 기존 모든 방 조회 접근 유지.
- `public/assets/lobby/sunset-court.webp`: 1회 생성한 글자 없는 배경.
- `public/assets/lobby/player-*.webp`: 현재 모델의 색상별 투명 이미지 6종. 비율/머리/어깨/신발 재설계 없음.
- `public/assets/lobby/ATTRIBUTIONS.md`: 출처·최종 프롬프트·변환 방법.
- `scripts/render-lobby-assets.mjs`: 게임 모델의 정적 에셋 출력. 홈페이지에서 import하지 않는다.
- `scripts/probe-player-lobby.mjs`: 핵심 브라우저 흐름 확인, 스크린샷 없음.

선택 색상 이미지 하나를 표시하고 CSS로 바닥 그림자를 준다. 현재 모델의 면 분할/관절 외형 한계도 그대로다.
캐릭터 영역만 향후 3D로 교체할 수 있으나 이번에는 별도 첫 화면 렌더링 시스템과 온라인 광장을 만들지 않았다.
760px 이하에서는 메뉴를 우선하고 캐릭터를 아래 보조 영역으로 줄인다. 낮은 데스크톱 화면은 메뉴 내부 스크롤을 사용한다.
모바일 게임 조작은 추가하지 않았다.

## 실행과 검증

Windows: `npm.cmd run dev:online`.
웹 타입 검사, 메뉴/닉네임/설정 저장/BGM 관련 테스트 8개, 웹 프로덕션 빌드 통과.
`node --import tsx scripts/probe-player-lobby.mjs`는 실제 Game 소스를 묶은 로컬 브라우저에서 다음을 확인했다.

- 첫 화면 Engine/Room/WebSocket 0, 메뉴 폭 약 38%, 이미지 로드
- 닉네임·색상 저장/반영, 1대1 목록·선택 모드 생성 화면, 잘못된 코드 오류
- 390px 화면의 가로 넘침 없음, 낮은 560px 화면에서 버튼 접근
- 연습 시작 시 Engine 생성, 첫 화면 복귀 시 해제
- 지연된 2대2 요청 취소 후 늦은 연결 정리와 게임 자동 진입 방지
- 브라우저 예외 0, UI 스크린샷/녹화 0

모든 캐릭터 WebP의 alpha 채널을 확인했다. 생성 도구 호출은 배경 1회이며 캐릭터는 실제 모델 출력이다.
미검증: 실제 청감/BGM 음량, 배포 환경, 실제 두 사용자 경기 회귀, 모든 화면 크기의 외형.
새 1대1 자동 매칭은 구현하지 않았다. 외부 배포·커밋은 수행하지 않았다.
